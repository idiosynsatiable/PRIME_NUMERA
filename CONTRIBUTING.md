# Contributing

PRIME NUMERA uses reviewed, evidence-based development.

## Rules

1. Use Conventional Commits.
2. Do not fabricate history, citations, authorship, test results, deployments, or completion claims.
3. Keep numerical systems mathematically distinct.
4. Calculation changes require deterministic fixture tests and documented methodology.
5. Historical/cultural claims require sources and classification of historical, disputed, reconstructed, modern, or entertainment-oriented material as appropriate.
6. Do not present interpretive numerology as established scientific personality prediction.
7. Do not create generic composite cultural systems from unrelated traditions.
8. Preserve accessibility, privacy, mobile performance, and reduced-motion behavior.
9. Never place secrets or private birth information in commits, fixtures, logs, screenshots, or public URLs.
10. A feature is not done merely because code exists.

## Definition of done

Applicable work must be implemented, tested, visually verified, mobile verified, accessible, documented, committed, CI-green, security checked, performance checked, analytics verified, deployable, and rollback-capable before being represented as complete.
