# Name Lab

The Name Lab recalculates deterministic name-based values as the user edits input and can compare variants side by side.

The `WHAT CHANGED?` layer must be arithmetic-first. It reports changed letter counts, the selected system's value for each changed letter, each contribution delta, and total raw-value delta before interpretation.

A change in spelling must never be described as guaranteeing money, relationships, health, status, or success.

Live calculation should remain local/client-side where practical so each keystroke does not require transmitting the name to a server.
