# Number Collision Engine

The Collision Engine has two layers.

## Deterministic pattern layer

May identify facts directly derivable from calculation output, such as repeated numerical values, shared values across systems, and defined cycle overlaps.

## Interpretive layer

May attach editorially defined concepts such as amplifiers, tensions, or bridges. These are explicitly labeled interpretations and stored separately from deterministic arithmetic.

## Rarity rule

No structure may be called rare, unusual, exceptional, statistically significant, or given a percentile unless a reproducible frequency model exists. That evidence must identify the population/model, assumptions, sample/enumeration method, and resulting frequency.

At foundation stage the engine deliberately returns `rarityClaimed: false`.
