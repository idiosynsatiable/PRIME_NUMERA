# Phase 1 Design Brief

Status: design direction awaiting visual concept production and handler approval.

## Experience thesis

PRIME NUMERA should feel like a luxury mathematical observatory: precise, alive, cinematic, collectible, highly readable, and mysterious without leaning on occult cliché.

## Material language

Near-black foundation, opal glass, smoked crystal, polished metal, restrained spectral refraction, deep cobalt, uranium-green micro-accents, and warm metallic highlights. Avoid generic purple-galaxy wallpaper, zodiac clipart, fake gold, crowded cards, and decorative particle noise.

## First viewport

Brand

YOUR NAME IS ALREADY A NUMBER.  
SEE WHAT IT BECOMES.

Full birth name + birth date + BUILD MY NUMBER DNA.

Secondary action: Just calculate my name.

Trust line: Pythagorean • Chaldean • Transparent calculations.

## Reveal choreography

Letters → values → equations → reductions → result → Number DNA assembly → interpretation access. Target 2–4 seconds, skippable, reduced-motion safe.

## Concept set required before final UI implementation

Desktop landing, mobile landing, calculator, calculation reveal, Number DNA, deep profile, Name Lab, timeline, compatibility, Symbolic Atlas, rune explorer, share card, Family Mode, 18+ Mode, and account/profile.

## Number DNA

The graph must remain information architecture, not particle decoration. Every visual node needs a corresponding accessible structured representation.
