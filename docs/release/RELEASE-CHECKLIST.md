# Candidate release checklist

- [ ] Candidate GitHub CI passes at exact published SHA
- [ ] Persistent single-host production volume provisioned with correct permissions
- [ ] Production origin and custom-domain HTTPS verified
- [ ] Stale Railway staged patch reconciled
- [ ] Correct branch, Docker build and start command selected
- [ ] Production health, create/open/revoke, PNG/QR and restart checks pass
- [ ] Privacy/access logs, backup retention, alerts and restore rehearsal evidenced
- [ ] Physical Android and iOS browser acceptance, screen-reader navigation and zoom checked
- [ ] Commercial name clearance and final editorial review concluded

Local test/build/accessibility evidence is recorded separately in ASTRA-VERIFICATION.md; unchecked external items are not inferred from local success.
