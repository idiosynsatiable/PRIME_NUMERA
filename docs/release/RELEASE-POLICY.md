# Release Policy

No public production release is authorized by ordinary implementation approval.

A release candidate requires evidence for calculation correctness, CI, responsive mobile behavior, accessibility, security, privacy, performance, analytics, source documentation, cultural-source documentation where applicable, monitoring, and rollback capability.

Commercial naming remains a separate trademark/domain/app-store/legal decision gate.

Production credentials, paid infrastructure commitments, destructive database operations, and public release require handler escalation under the PRIME NUMERA protocol.
