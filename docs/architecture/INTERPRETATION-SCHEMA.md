# Interpretation Architecture

Interpretation content is versioned data and cannot alter deterministic calculations.

Every interpretation record should identify:

- stable ID and version
- calculation/system applicability
- category: `traditional`, `modern`, `entertainment`, or `historical-context`
- source references where claims depend on sources
- editorial status
- locale/language
- content safety/age mode where relevant

Scientific-evidence statements are separate from numerological interpretation. PRIME NUMERA must not imply that an arithmetic result scientifically establishes personality, compatibility, future events, health, wealth, or relationship outcomes.

Collision interpretations reference calculation IDs/graph nodes. They never overwrite their values.
