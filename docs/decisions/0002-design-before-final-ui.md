# ADR 0002: Design before final interface implementation

Status: Accepted

## Decision

Do not treat the first coded UI as the final interface. Phase 1 produces coordinated design concepts for desktop/mobile landing, calculator, reveal, Number DNA, deep profile, Name Lab, timeline, compatibility, Symbolic Atlas, rune explorer, sharing, Family Mode, 18+ Mode, and account/profile.

After owner approval, the design system is extracted and implementation is visually compared against accepted concepts.

## Why

The product's differentiation depends on a coherent “luxury mathematical observatory” experience rather than a generic dashboard assembled from unrelated cards.

## Constraint

This ADR does not block foundational non-visual engineering such as deterministic calculations, schemas, tests, research registries, privacy architecture, and CI.
