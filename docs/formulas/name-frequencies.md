# Name Frequency Derivations

The foundation engine exposes raw frequency facts before attaching traditional labels.

For a selected system, it counts occurrences of each supported numerical value in the normalized name.

Derived values:

- Missing values: supported values with zero occurrences. These may feed a Karmic Lessons interpretation layer after methodology review.
- Hidden Passion candidates: value or tied values with the greatest occurrence count.
- Subconscious Self count: number of supported numerical values represented at least once.

The arithmetic is deterministic. Meanings assigned to these values belong to the interpretation layer and require methodology/source documentation.
