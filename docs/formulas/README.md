# Formula Registry

This directory is the human-readable methodology registry for deterministic calculations.

## Foundation implementation

### Expression / Destiny

Input: normalized supported letters from the supplied name.

1. Normalize according to the explicit name policy.
2. Map each supported letter using the selected system only.
3. Sum mapped values.
4. Reduce using that system's selected reduction/master-number policy.
5. Return the complete mapping, sum, reduction steps, and final value.

No interpretation is part of this calculation.

## Research gate

Published-reference fixtures and historical/methodological citations must be added before claiming methodology research is complete. The labels “Pythagorean” and “Chaldean” describe conventional modern numerology systems here; stronger historical-origin claims require source evidence.
