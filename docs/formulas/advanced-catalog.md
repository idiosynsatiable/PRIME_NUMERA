# Advanced Calculation Catalog

Status: implementation primitives added; published-source fixture review remains required before release claims.

## Balance

The current primitive derives initials from each normalized name word, maps those initials through the selected numerology system, sums them, and applies an explicit reduction policy. The returned result preserves initials, mapped values, aggregate, reduction steps, and final value.

## Planes of Expression

Planes are represented by a named methodology object rather than hard-coded interpretive truth. The initial configurable Western grouping is:

- Physical: values 4, 5
- Mental: values 1, 8
- Emotional: values 2, 3, 6
- Intuitive: values 7, 9

The engine reports participating letters, counts, and raw mapped totals. Interpretive claims remain outside the deterministic layer.

## Release rule

These calculations must not be described as historically universal. Before release, the chosen methodology needs source provenance, reference fixtures, and explicit UI labeling. Alternate documented methodologies should be modeled as separate configuration rather than silently blended.
