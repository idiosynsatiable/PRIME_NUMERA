# Karmic Debt Values

The engine can detect the conventional modern numerology values 13, 14, 16, and 19 when they occur at explicitly supplied arithmetic stages.

Detection is not interpretation. The returned occurrence includes its source so the UI can show exactly where the value appeared.

Whether a particular methodology treats a pre-reduction compound value, birthday value, or another stage as a “Karmic Debt” must be controlled by methodology configuration and documented sources. The software must not scan arbitrary intermediate numbers and then imply significance without defining the rule.
