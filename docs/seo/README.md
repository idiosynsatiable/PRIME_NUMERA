# SEO / Discovery Architecture

Discovery pages must provide genuine unique value and transparent methodology rather than keyword-farm content.

Planned information architecture includes canonical number pages, calculation explainers, system explainers, and methodology guides. Structured data is used only where semantically applicable.

Requirements before production include canonical URLs, OpenGraph metadata, social-card metadata, sitemap, robots directives, semantic HTML, and Core Web Vitals verification.

Private profile inputs and birth data are never SEO content. Public-safe shares must be explicitly user-created and separately controlled from indexable editorial pages.
