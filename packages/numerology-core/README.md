# @prime-numera/numerology-core

Pure deterministic calculation package for PRIME NUMERA.

## Purpose

Provide auditable numerical results without UI, persistence, network access, analytics, or interpretive prose affecting arithmetic.

## Current foundation

- Explicit Pythagorean mapping table.
- Explicit Chaldean mapping table.
- Configurable master-number reduction.
- Latin-name normalization with visible ignored-character reporting.
- Expression/Destiny calculation returning mappings, intermediate sum, reduction steps, and final value.

## Not yet implemented

The broader calculation catalog, Unicode/non-Latin policies, vowel/Y policies, date calculations, published-reference fixtures, and historical-source corpus remain release work. They must not be represented as complete until implemented and verified.

## Security/privacy

The package is pure and does not persist input. Applications consuming it remain responsible for consent, storage, logging, telemetry, and public-share privacy controls.
